快捷鍵

  • 空白鍵 播放 / 暫停　Home 回到起點（或區段起點）
  • ← / → 上一小節 / 下一小節　PageUp / PageDown 翻頁模式：前後一頁；捲動模式：捲一個畫面（播放中自己捲動會暫停跟隨，按播放或跳小節恢復）
  • 工具列 沒用到會往上收起；滑鼠移到畫面上緣（或按上緣的小標籤）叫出來，按播放時立刻收起。收起時右上角顯示樂章、小節與拍數
  • 點擊小節 跳到該小節　Shift+點擊 設為區段起點　Alt+點擊 設為區段終點
  • [ / ] 以目前小節設為區段起點 / 終點　L 開關循環
  • + / − 速度 ±5%　M 拍點 關 / 全曲 / 指定區段
  • E / Shift+E 下一個 / 上一個「拍數不符」小節
  • Esc 取消選取 / 離開修正模式

紅色小節 = 該聲部的音符時值加總與拍號不符，很可能是辨識錯誤；粉紅 = 空小節。紅色小節在播放時會被拉長到最長聲部的長度，各聲部在該小節內對不齊，修正後即恢復。

各聲部小節數不一致多半是「多小節休止」只被認成一小節：在修正模式選該小節的休止符，按 I 補上缺的小節數；多認的小節用 X 刪除。可用拍號變換（樂章交界）核對各聲部是否對齊。

辨識錯誤較多時：下載 MusicXML → 用 MuseScore Studio 修正 → 另存 MusicXML → 重新上傳（同作品、同聲部名稱）。
